# Dados faltantes (Nam) em dataSet

Esse projeto mostra como achar e corrigir informações que estão faltando em uma tabela usando Python e Pandas. Usando dados de atletas olímpicos, o código descobre o que está em branco e preenche os vazios — por exemplo, colocando "Zero" onde não tem medalha e calculando a média das alturas. O objetivo é deixar a tabela limpa, organizada e pronta para ser usada sem dar erros.
